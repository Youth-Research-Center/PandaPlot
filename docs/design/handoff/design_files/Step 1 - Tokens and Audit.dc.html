What the system has today

TOKENS~30 keys in one dict per theme (text ×5, border ×3, surface ×3, accent ×4, status ×4, radius ×4). The accent is user-configurable.
STYLINGGlobal QSS keyed on dynamic properties ([primary], [chip], [segment], [card]), plus per-widget stylesheets and QPainter.
COMPONENTS15 shared widgets. The core set is PButton, SegmentedControl, ValueComboBox, SliderWithSpinbox, ToggleSwitch, ChipRow, Card, SectionHeader and DirtyFooter.
STORYBOOKOne story per widget with live controls and a Light/Dark/System switch. Contrast is unit-tested for 2 color pairs.
